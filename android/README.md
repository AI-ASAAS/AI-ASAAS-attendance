# تطبيق أساس Android — مصدر قيد التحقق

المتطلبات: Android Studio مع JDK 17 وAndroid SDK 35 وGradle 8.9. افتح هذا المجلد كمشروع Gradle؛ لم ترفق ملفات wrapper التنفيذية المنزلة تلقائياً.

الوظائف المكتوبة: دخول الموظف، مسح QR، موقع دقيق، خدمة أمامية ظاهرة بإشعار أثناء الحضور، إرسال قراءات الموقع للخادم، إيقاف التتبع بعد الخروج، تخزين مشفر بمفاتيح Android Keystore، وأدلة انقطاع اتصال ترسل للمراجعة فقط.

التطبيق يقبل HTTPS فقط ويقارن رابط QR بنطاق الخادم المحدد. لا يتبع تحويلات HTTP. الدخول عبر المتصفح مستقل ولا يشارك رمز الجلسة معه.

لا يطلب تتبعاً دائماً خارج الدوام، ولا يعيد تشغيل نفسه بعد فرض الإيقاف من إعدادات الهاتف. عند ذلك تظهر قراءة الموقع قديمة في الداشبورد. يلزم اختبار فعلي على أجهزة الشركة، مع الشاشة المغلقة وتوفير البطارية وانقطاع الشبكة وسحب الأذونات. لا تعتبر ملفات المصدر APK جاهزاً أو اختباراً لخروج GPS فعلي.

قبل التوزيع: بناء التطبيق، اختبارات الجهاز، ضبط شهادة HTTPS وإعدادات الخلفية، إضافة أيقونة الهوية بالشكل المناسب، وتوقيع إصدار release بمفتاح تملكه الشركة. لا تحفظ مفتاح التوقيع في Git.
